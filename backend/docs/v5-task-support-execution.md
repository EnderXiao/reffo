# V5 匹配信号传递修复记录

日期：2026-09-08。执行范围为发布前诊断中的任务支持范围问题，不同时调整摘要长度、技能文风、数字保留策略或成品框架。

后续测试：[跨案例准备与 S09 真实 Writer 结果](./v5-crosscase-regression-result.md)。本记录的零外呼和回放结论保留为对应修复时点状态。

## 已实现

1. 新增 `writing/task-support.ts`，区分两类集合：
   - 任务相关性：任务、属性、条件及复合要求的相关关系，可用于排序和分组；局部实践仍有选材价值。
   - 独立任务支持：只有该任务自身的 direct / transferable link 及合法源事实，才能进入写作主题、编辑指引中的明确任务 ID 集合；关联属性不展开为多个任务的证明。
2. Writer 内部输入增加 `independent-task-evidence-v1` 标记，以及 direct_task_evidence / transferable_task_evidence / partial_task_evidence / related_context 关系描述，保留原始 status 和已有差异说明。弱信号和可迁移经验不被删除，不把所有关联降为 unknown。
3. P03 代码校验增加非阻断诊断 `JOB_FIT_RELATED_TASK_UNPROVEN`：当直接匹配的非任务目标关联到尚未独立支持的任务时，提示不能继承为任务证明。它不自动修改原判断、不清空事实、不触发再次外呼。
4. 新标记只在新建写作计划时赋值；序列化历史冻结计划不会偷偷追加新策略或改写历史请求。

这是代码和内部输入契约修复，不是新增大模型节点。P03 / Writer 提示词正文和版本、4320 输出额度、公共简历结构、生产默认模式均未改变。非定向旧写作路径不启用新关系标记。
