## 已实现

### 1. 时间状态提示词

P01/P01R 升级 r18：依据原文“已批准、尚未批准、待批准、拟任、计划”等状态表达，不依据知识截止时间或日期外观猜未来。批准只证明原文自述的审批状态，不代表任职、上线或结果已发生；保留本人确认等限定，不提供外部认证。

存在 future_or_planned 时，模型提供可选 `temporalRiskQuote`：对应风险的完整原文句（包含句末标点）；不能只摘“批准”而忽略“尚未”。不存在风险时省略字段。仍为 9 个根字段、每目标 block 一份标注，新增的是**事实候选内部的可选字段**，不是宣称传输完全没有变化。旧候选仍可解析，但不凭空得到新引用。

### 2. 确定性局部处理

`temporal-risk.ts` 在现有风险归一化之前执行，不新增 Agent、修复调用或质量阻断循环。

仅当以下全部成立时隔离风险：

- 事实逐字覆盖完整源块，唯一标注，无其他注入/冲突/敏感/未决风险；不恢复已 excluded 内容。
- 风险引用唯一对应完整的末句，包含计划/未决信号；不能跨块、摘取子串、吞掉否定或有重复引用歧义。
- 块内共 2–3 个完整句子；其余句能独立表达明确的当前职责或已完成工作，不包含未来、条件、指代依赖。计划标题或只读锚点上下文会阻止拆分。
- 风险句不能否认、撤回、更正或指代前面的工作；句子原文拼回后与完整源块逐字一致。
- 现有事实容量有余量，派生 ID 不冲突；不扩大 storage 上限。

满足时：当前职责保留为 source_qualified，风险末句保留原有风险并 excluded；不删除风险句、不升格到 source_supported。服务端重建各片段偏移、数字索引，并更新时间线、章节和质量评语的引用，保持同一 source block / scope。风险只能局部作用，不迁移到其他经历。

不满足时：不猜测、不清除标签、不造证据，沿用原风险处置并记录 `TEMPORAL_RISK_SCOPE_UNRESOLVED`。已成功隔离的风险句在后续重复校验中保持 excluded，不重复制造新事实。

### 3. 验证范围与指纹

- `temporalRiskQuote` 经过 Schema/紧凑 materializer 兼容验证；不写入用户成品 EvidenceAtom 或公开新增板块。
- 新模块、候选类型、Schema、提示词和校验器均在抽取实现摘要内；旧缓存不能跨实现冒充新验证。
- `TEMPORAL_RISK_LOCALIZED` / `TEMPORAL_RISK_SCOPE_UNRESOLVED` 进入隐私安全的观察代码白名单，不将原文引用放入共享诊断日志。
- 代码只对有证明的有限句法形态处理，不宣称正则能理解全部语言、时间线或履历。逗号混合句、长段、条件句、跨句指代、未知表达与容量不足均不自动拆分。
