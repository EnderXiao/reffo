# V5 任职正文覆盖修正 r4

日期：2026-09-08。仅作用于已显式启用的 entry-writing-v1 路径，不修改生产默认开关。

## 实现

1. 确定性计划为有可用独立业务证据的任职预留一条正文，优先较近任职；预算不足仍有上限，不保证无条件扩写所有任职。保留现有重复时间线抑制，类型多样性替换不得移除这些保留证据。
2. 对仅剩时间线、同 scope 下有无风险原文范围清单的任职，生成服务端固定范围说明。只允许原文复制，不把它升级为成果，不借用其他项目。固定说明计入现有列表预算。
3. 最终校验仅针对可重新计算、完全匹配的固定范围说明放行非业务类型证据；跨 scope、增加成果或修改原文仍不允许。
4. P06C entry 提示词升至 r4：每个输入任职至少写一句实际正文，较早任职精简，固定范围说明不重复生成。
5. 本轮实际响应出现无来源“主导形成”。在原始段落引用范围内，仅删除无依据“主导”修饰且其后动作在同条源材料中存在的有限模式；已明确主导的原文、否定表达不作此改动。保留警告与原始响应，再执行完整校验。

## 限制

本轮没有实现可靠的跨 scope 任职—项目关联模型；不能把同公司项目自动归到某一任职。固定范围说明是最低完整性修复，不等于优秀贡献表达。列表合并仍使重点经历过长，单例成功不等于上线质量或独立招聘人员验收。
