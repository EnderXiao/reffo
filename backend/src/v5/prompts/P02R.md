当 originalEnvelope 中 jobTargetingPolicy=job-targeted-v2（历史v1回放同样保留），还须返回完整 jobSuccessProfile。修复画像的来源、关联、metricQuote 和条件性质，不删除画像退回旧契约。画像允许基于任务的合理推断，但必须标为 inferred 并保留依据；unknown 不凑值，推断不得升级必要资格。job: 前缀节点只代表岗位判断，不是候选人事实；六类属性无需填满。不增加外部来源或新 KPI。下方“不得增加原文未出现的要求”针对事实提取与硬要求，不禁止保留明确标注的成功条件推断。

修复规则：

candidatePortrait 是可选的一句话综合画像，采用 id/text/provenance 节点，标 inferred 并给 JD 来源与简短依据；不得从候选人反推画像，不保证稳定绩效。可为 null，不因缺少这段展示总结重新调用模型。

画像中的成功条件说明任务成功所需的过程、资源或判断，不重复预期结果。专项工作需独立 task；不把“模型评估”和普通开发迭代视为同一种能力。缺少年限单位或标题/正文矛盾时保留不确定性，不补单位或强行决定门槛。

1. 返回完整 JobExtractionCandidate，不得只返回发生变化的字段。
2. blockRelativeSpan 使用 JavaScript UTF-16 索引和半开区间 `[start, end)`：start 包含，end 不包含。必须满足 `0 <= start < end <= block.text.length` 且 `block.text.slice(start, end) === verbatimText`。
3. 遇到 JD_QUOTE_NOT_FOUND 或 JD_SPAN_MISMATCH 时，verbatimText 必须复制 sourceBlockId 对应 block 中逐字连续的文本，保留项目符号、标点、大小写和空格。单条短 block 优先复制整个 block，并设置 `{start: 0, end: block.text.length}`；其他引用设置 `end = start + verbatimText.length`。禁止使用闭区间、把 end 多加 1，或添加“负责”“需要”“能够”等原文没有的前缀。
4. 修复 quote/span 时，按该独立语义方面从对应 sourceBlockId 重新选择最短完整连续原文与真实 span；单一语义短块可引用整块，复合块不得扩回整块而丢失原子性。这是从来源重新提取，不把改写文本当证据。只有 block 明确不是岗位事实时才删除候选，并同时写入 unmappedFragments；uncertainties 不计入 block 覆盖。
5. 不得增加原文未出现的要求、公司事实或地点假设。每项 validationIssue 都是强制验收条件。
6. block 为来源容器，不是固定一条要求。学历、年限、行业偏好和需不同证据的独立任务须分别提取，保留准确限定。修复 JD_COMPOSITE_QUALIFICATION_UNSPLIT 时独立拆出学历、工作年限、优先行业经验，优先只作用于实际对应项；JD_NUMBERED_REQUIREMENTS_MERGED 按独立编号拆分。允许同一 block 多要求、基本信息共用来源；不能以整块覆盖替代语义完整。mapped/unmapped 仍互斥且覆盖来源。
7. logicGroupLocalId 与 logicOperator 必须成对填写；默认都为 null。只有 JD 原文明示两个或更多独立 requirementCandidate 存在跨项“且”“或”“满足其一”关系时，才给相关项填写相同 group 和对应 operator。遇到 INVALID_REQUIREMENT_LOGIC 或任何单边填写时，若原文没有上述跨项逻辑，必须将两项都改为 null，不得把普通列表强行编成逻辑组。
8. 混合招聘摘要同样按独立语义提取。遇到 JOB_PROFILE_SUMMARY_QUALIFICATION_MISSING 时，在保留原基本信息的同时，为摘要中的每个明确学历/带“年”单位的年限分别建立独立 requirementCandidate，并同步加入 jobSuccessProfile.requirements。例如“长沙/15-30K·13薪/3-5年/本科”中的“3-5年”（experience）和“本科”（education）各用不同 localId、逐字短 quote 和真实 span；同一 block 可同时出现在 basicInfoSourceBlockIds 与多个 requirementCandidate 中，不要把这两个短 quote 扩成完整摘要或合成一项。不补缺失单位，不把区间上端推为排除候选人的硬上限；必要性不明确时 condition=unclear，仍保留为待核验条件。不从“海外”标题追加英语、签证或海外工作经历等原文未明示的门槛。
9. 仅含地点、薪资、学历和年限的短摘要只支撑基本信息与独立资格，不额外整行建立 category=other 等能力要求；修复漏提时必须删除这类旧整行候选并清理其画像引用，不能只追加资格而留下重复项。遇到 JOB_PROFILE_METADATA_NODE_INVALID 时，移除仅由地点薪资摘要构造的虚假任务/能力，真实业务节点仍须保留业务来源。不得删除包含真实业务动作的复合条件。quote 必须保留原文连字符和单位；“3-5年”不能称为单位缺失，“多年”与该区间本身不构成冲突；3-5年预期范围和正文3年以上兼容，不推断5年硬上限。原文从0到1未写主导不补主导，基本分析不升级体系建设，独立完成等明示职责边界必须保留。
