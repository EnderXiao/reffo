# Reffo Prompt v4.1 真实材料机器 A/B 报告

## 结论

v4.1 在岗位定制质量上显著优于现版，但未通过完整机器最低门槛，不能标记为上线候选。

- 测试集：10 份唯一真实简历、30 份唯一真实 JD，共 30 个一岗一简历样本。
- 现版平均分：51.74。
- v4.1 平均分：81.40。
- 绝对提升：29.66 分。
- 相对提升：57.32%。
- 配对样本平均增益的 95% 置信区间：23.36–35.96 分。
- 30 个样本中：29 个提升，1 个下降；增益中位数 28.875 分。
- 120 次顺序互换盲评：v4.1 胜 112、现版胜 2、平局 6、未知 0。
- v4.1 机器盲选胜率：93.33%，通过 70% 门槛。
- 确定性事实闸门失败：0，通过零失败门槛。
- 最终资格状态：pass 12、uncertain 2、fail 16。
- eligibility=pass 的 12 个样本中，9 个 deliverable；通过率 75%，低于 90% 门槛。

因此机器门槛总体结果为 **未通过**。

## 研究覆盖

- 公开研究覆盖 16 家公司、30 个岗位、43 个公开来源。
- 每个岗位至少有一个官方或监管披露来源。
- 29 个岗位的 research_status 为 partial，1 个为 complete。
- 19 个岗位没有找到足够可靠的员工口碑来源，相应字段保持 unknown，没有用模型记忆补齐。
- 无法从公开证据唯一确认直属上级时保持 unknown，没有把公司高层自动写成直属上级。

## 主要收益

1. 用原子证据账本替代普通结构化简历，生成句可回溯到 evidence_id。
2. 将 JD 明示事实、公开网络事实、推断和未知严格分层。
3. 先做资格门禁，再做匹配分，避免高文案分掩盖学历、年限、届别、地点或作品集等硬门槛。
4. ATS、招聘经理、证据密度三种策略并行生成，由独立 Judge 盲选。
5. 最多两轮定向修订，并用确定性事实闸门和 LLM Judge 双重拦截。
6. 面试建议绑定 requirement_id 与 evidence_id，公开情报只用于压力测试和反问。

## 未通过原因

三个 eligibility=pass 样本没有达到 deliverable：

1. `resume_06:resume_06_job_03`：关键作品集要求未被满足，最终 82 分。
2. `resume_07:resume_07_job_02`：修订时删除了数字前的“约”，把不确定数字升级为确定数字，事实忠实度归零；这是唯一平均分下降样本，v4.1 比现版低 10.5 分。
3. `resume_09:resume_09_job_03`：高级 SQL 等关键证据不足，最终 75 分。

最终 LLM Judge 在 7 个不可交付样本中识别到 8 条潜在未支持陈述，并全部阻止交付。说明门禁有效，但生成与修订的事实稳定性仍不足。

## v4.2 必修项

1. 增加数字限定词逐字保护：`约/近/超过/至少/最多/不足` 与数字、单位组成不可拆分的原文事实单元。
2. 修订采用“只接受不回退”策略：新版本若事实分、总分或资格状态变差，自动回滚到历史最佳候选。
3. 第二轮修订前重建允许陈述白名单，并对上一轮新增或改写句做逐句证据差分。
4. 统一匹配 Agent 与最终 Judge 的资格口径；作品集、SQL 等 knockout 缺口不能一边判 pass、一边判不可交付。
5. 对缺失且无法通过现有证据修复的硬门槛停止润色，输出 blocked/verify_with_user，而不是继续改写两轮。
6. 将数字限定词、资格矛盾和 trace 完整性加入确定性闸门，弥补仅靠技能/所有权词典的漏检。
7. 保留候选级与修订级格式自动修复，并对 socket 关闭、空响应、传输 JSON 截断执行最多三次瞬时重试。

## 成本与验证

- DeepSeek Pro：682 次已结算调用，估算 4.633193 美元。
- DeepSeek Flash：62 次已结算调用，估算 0.258875 美元。
- 合计估算：4.892068 美元。
- 成本包含失败批次和重试批次中已返回 usage 的调用；客户端在收到 usage 前中断的极少数请求可能不在本地估算内，以 DeepSeek 账单为准。
- 后端全量测试：63 passed、0 failed。
- TypeScript：`bunx tsc --noEmit` 通过。
- 数据门禁和公开研究门禁均通过。

## 尚未执行的最终验收

当前不建议先投入人工全量评审，因为机器 deliverable 门槛未通过。v4.2 通过机器门槛后，最终验收仍需要：

1. 两名独立招聘评审覆盖 30 个样本。
2. 一个不同供应商或不同模型族的独立模型 Judge。
3. 人工与独立 Judge 的事实错误、硬资格漏判、修订事实回归全部为 0。
