腾讯|S2-CSIG 财务管理(产品财务 BP)
深圳|CSIG|10年以上经验|更新 2026-07-21

职位介绍
为 CSIG 产品与业务线提供全面财务管理,覆盖分析、核算、税务、资金、风险和内部控制。

岗位职责
1. 支持业务线预算、预测和经营分析,向管理层呈现关键驱动与风险。
2. 参与产品商业模式、定价、投入和项目决策,建立财务测算与跟踪机制。
3. 统筹核算、税务、资金和内部控制要求,保障业务合规与财务质量。
4. 连接业务与财务职能团队,推动问题解决和管理机制持续优化。

任职要求
1. 本科及以上,10年以上财务管理或业务财务经验。
2. 具备战略财务、经营分析和复杂商业问题判断能力。
3. 熟悉预算、核算、税务、资金、风险和内控等财务领域。
4. 沟通影响力强,能面向高级管理者推动跨团队决策。

加分项
- 有云计算、企业服务或科技产品财务经验
- 具备 CPA、ACCA、CMA 或同类专业背景
