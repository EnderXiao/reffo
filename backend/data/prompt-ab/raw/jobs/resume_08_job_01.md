北京|Seed|Job ID A222097

职位介绍
负责 Seed 团队端到端招聘,建立关键人才管道,并通过人才市场洞察支持业务增长。

岗位职责
1. 负责职位分析、人才寻访、筛选、评估、录用和入职衔接等全流程招聘。
2. 深入理解业务与人才画像,制定招聘策略和渠道组合。
3. 开展人才地图和市场研究,持续建设关键岗位候选人管道。
4. 管理业务方与候选人沟通,跟踪招聘数据并持续优化流程和体验。

任职要求
1. 本科及以上,3年以上招聘相关经验。
2. 具备独立负责职位和人才寻访的能力,理解结构化评估方法。
3. 沟通、协调和项目推进能力强,能够管理多个招聘优先级。
4. 对人才市场敏感,具备结果导向和良好的候选人意识。

加分项
- 有 AI、算法、研发或前沿技术招聘经验
- 有高端人才地图和定向寻访经验
