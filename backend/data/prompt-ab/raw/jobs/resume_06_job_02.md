腾讯|企业微信-交互设计师
广州|企业微信|2年以上经验

职位介绍
负责企业微信移动端、桌面端和 Web 端体验设计,面向复杂企业协作场景形成清晰、可用的交互方案。

岗位职责
1. 参与产品前期创意和方案讨论,理解用户、业务目标和使用场景。
2. 负责移动端、桌面端及 Web 端的流程、信息架构和交互设计。
3. 通过结构化推导解决复杂产品问题,并清晰说明设计逻辑和取舍。
4. 与产品、视觉和研发团队协作,跟进实现质量并持续迭代。

任职要求
1. 2年以上互联网产品交互或体验设计经验,有完整作品集。
2. 掌握交互设计方法,能够理解复杂产品逻辑并建立清晰的信息结构。
3. 重视细节、可用性与多端一致性,具备较强的原型表达能力。
4. 具备良好的沟通协作和项目推进能力。

加分项
- 有企业协作、SaaS 或效率工具经验
- 有用户研究或设计系统经验
