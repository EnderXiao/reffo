Amazon|Senior Financial Analyst, Global Logistics, Global Logistic Finance
上海|Finance & Global Business Services|Job ID 10478834

职位介绍
负责 Amazon Global Logistics 欧洲进口业务的运费成本、月结、预测和自动化财务验证,支持从中国起运到欧洲履约中心的端到端物流经济性管理。

岗位职责
1. 负责欧洲进口运费月结、计提、实际与预测差异及管理层说明。
2. 建立并维护按集装箱、计费重量和费用代码拆分的运费成本与费率模型。
3. 支持年度与滚动规划、情景分析、成本桥接和降本项目。
4. 使用高级 Excel 和 SQL 处理大规模数据,并推动财务工具自动化、标准化和可扩展。

任职要求
1. 3 年以上税务、财务或相关分析领域经验,并有使用关键财务指标开展分析的经验。
2. 具备通过自动化和分析改善财务流程、工具与管控的经历。
3. 工程、统计、商业等本科学位,或同等量化岗位经验。
4. 具备用于数据挖掘和商业智能的高级 SQL 能力。

加分项
- 了解 Tableau 及大规模数据报告工具
- 熟悉 Oracle、SAP、Essbase、Cognos 等财务或分析系统
