腾讯|微信小游戏-数据科学(生态分析方向)
深圳|微信事业群|1年以上经验|更新 2026-07-01

职位介绍
围绕微信小游戏生态开展定量与定性研究,形成生态认知、增长判断和产品运营建议。

岗位职责
1. 结合定量分析和定性研究,建立对小游戏生态、用户和开发者的系统认知。
2. 识别生态增长机会与关键问题,为产品、运营和商业化决策提供数据支持。
3. 运用数据挖掘方法支持用户增长、内容推荐及精细化运营。
4. 与产品、运营和算法团队协作,推动分析结论进入策略与迭代。

任职要求
1. 统计、数学、数据科学、经济或相关专业本科及以上。
2. 1年以上数据科学、商业分析、策略分析或人工智能相关经验。
3. 具备扎实的统计分析和数据处理能力,熟悉 SQL、Python 或同类工具。
4. 对内容、游戏或平台生态有兴趣,能够独立拆解复杂业务问题。

加分项
- 有内容平台、游戏或用户增长分析经验
- 有推荐、实验或因果分析实践
