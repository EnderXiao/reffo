美团|商业分析实习生
北京|校园招聘|Job Union ID 4548532384|发布 2026-06-15

职位介绍
加入美团业务团队,以用户数据分析、标签体系和策略研究支持产品与运营决策。

岗位职责
1. 协助开展用户数据挖掘与统计分析,围绕业务目标形成分析思路和策略建议。
2. 参与用户标签的探索、建设和准确性优化,支持精细化运营和用户研究。
3. 分析用户行为、业务漏斗和关键指标,识别异常及潜在增长机会。
4. 与产品、运营和数据团队协作,完成取数、分析、汇报与效果跟踪。

任职要求
1. 本科或研究生在读,统计、数学、计算机、经济或相关专业。
2. 具备数据分析基础,能使用 SQL、Excel;掌握 Python 等分析工具者优先。
3. 逻辑清晰、数据敏感,能够把分析结论转化为业务语言。
4. 具备良好的沟通、学习和团队协作能力。

加分项
- 有互联网、零售或本地生活分析实习经验
- 有用户分群、标签或增长分析项目
