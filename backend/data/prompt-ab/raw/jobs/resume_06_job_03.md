Apple|UX Designer
洛杉矶|Design|Role Number 200654232-2605|发布 2026-03-29

职位介绍
在 Apple 设计团队中负责复杂数字体验的用户体验设计,从问题定义、用户流程和交互方案到高保真交付参与完整产品周期。

岗位职责
1. 与产品、研究、工程和内容团队共同理解用户需求与业务目标。
2. 产出用户流程、信息架构、线框图、交互原型和高保真设计。
3. 通过评审、测试和迭代解决复杂交互问题,保证体验的一致性与可用性。
4. 清晰表达设计逻辑、权衡和系统规则,推动跨团队达成决策。

任职要求
1. 具备数字产品 UX 或产品设计经验,并有完整作品集。
2. 熟悉以用户为中心的设计流程、交互设计和原型工具。
3. 能够处理复杂信息与多方约束,兼顾细节和系统性。
4. 具备优秀的视觉、口头和书面沟通能力。

加分项
- 有大型消费产品或跨平台体验经验
- 有用户研究、无障碍或设计系统经验
