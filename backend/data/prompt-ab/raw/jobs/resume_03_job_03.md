上海|Digital|Job ID 546763|发布 2026-07-01

职位介绍
负责 adidas 大中华区电商相关业务的经营与协同,围绕消费者、商品、平台活动和数字渠道表现推动增长。

岗位职责
1. 制定电商业务计划并跟踪核心经营指标,及时识别销售、流量、转化和库存风险。
2. 协同商品、市场、会员、内容与供应链团队推进平台活动和重点项目。
3. 分析消费者与渠道表现,形成经营复盘和可执行的优化建议。
4. 推动跨团队项目按时间和质量要求交付,并沉淀可复制的运营机制。

任职要求
1. 具备电商、数字零售或平台运营经验,理解完整的线上经营链路。
2. 具备数据分析和商业判断能力,能够用指标推动行动。
3. 能够在矩阵组织中协调多个职能并管理项目优先级。
4. 具备良好的中英文沟通能力和结果导向意识。

加分项
- 有运动、服饰或消费品牌电商经验
- 有会员运营、全渠道或内容电商项目经验
