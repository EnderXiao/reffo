## 1. 整体结构

- 顶部为浅蓝色大背景块，不是很重的卡片或导航条。
- 页面主背景接近 `#F4F4F4 / #F5F5F6` 的浅灰白。
- 页面纵向结构：顶部按钮 → 品牌/策略区 → 进度文案 → 大卡片堆 → CTA → 灰色免责声明。

## 2. 顶部按钮

- 左侧按钮文案：`+ 源简历`
- 右侧为圆形 GitHub 按钮
- 两者都悬浮在浅蓝背景块之上，留白较宽松

## 3. 品牌态（图 1）

- Logo 居中，位于标题上方
- 标题为：`一个岗位，一份简历`
- “岗位”“简历”两处高亮蓝色，其余为黑色
- 标题字号较大，横向展开明显，不是紧凑堆叠

## 4. 策略态（图 2）

- 左上小标题：`Reffo 优化策略 ✦`
- 下方正文是两段大号黑体文案
- 文案宽度较大，行高宽松，但整体块仍靠上，不应被大空白推下去

## 5. 卡片堆

- 前景卡明显更大，占屏宽度较高
- 前景卡为：`灰底 + 大面积黄绿色几何圆块纹理`
- 前景卡文字为白色，不是深灰色
- 卡片顶部有深色横向把手
- 左下角悬浮蓝色评分块，内容：`88 %` / `完整度`
- 后方卡片需要露出更多不同颜色与纹理，而不是统一被压暗到只剩轮廓

## 6. 进度与右侧索引

- 进度文案较浅：`当前简历 1/10 项`
- 右侧字母索引非常轻，灰度低、细线多、存在较多刻度

## 7. 底部 CTA

- CTA 宽度并非全宽，而是中等宽度胶囊按钮
- 文案：`+ 创建 Reffo 简历`
- 下方免责声明为浅灰色，并与按钮有明确间距

## 8. 当前收口优先级

1. 卡片主题材质和尺寸
2. 顶部品牌态 / 策略态的垂直节奏
3. 右侧索引轻量感
4. CTA 与免责声明的间距
