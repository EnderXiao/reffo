# Reffo 个人信息处理清单

**审计基准日：2026 年 8 月 22 日**  
**对应协议版本：1.0.0**

## 一、口径说明

- “代码证实”表示当前仓库存在明确的读取、传输、持久化或删除实现。
- “可能敏感”表示简历字段本身未必当然属于《个人信息保护法》所列敏感个人信息，但具体内容或组合泄露后风险较高；若包含身份证件、健康、金融、特定身份等则属于敏感个人信息。
- “出境”按当前生产区域和服务合同判断。Supabase 项目区域及实际托管位置未知，不能写成“不出境”。
- 下表不输出任何环境变量值、密钥、令牌或密码。

## 三、代码审计确认“不存在”的处理活动

截至审计日，在当前 H5 业务代码中未发现以下处理：

- 应用自行设置 Cookie；
- IndexedDB、Service Worker 或 CacheStorage 业务数据；
- 广告 SDK、营销 SDK、用户画像或跨站跟踪；
- 产品分析埋点；
- 第三方错误监控 SDK；
- 支付、订阅、自动续费或退款；
- 公开用户案例；
- 把用户简历写入 Reffo 自有模型训练集；
- 常态化人工查看或人工审核简历；
- H5 主动调用相机、麦克风、定位、通讯录、相册；
- 产品内公开注册和账号注销。

“不存在”仅代表当前被审计仓库，不代表浏览器、部署商或第三方平台绝不产生技术日志。生产部署后应通过浏览器网络面板、响应头、托管控制台和合同再核验。
